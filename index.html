Attendance settings

Late arrival is calculated only when IN time is more than the reporting time plus the grace period. The fee is a tracking field, not an automatic wage deduction. Check applicable employment and wage rules before applying any deduction.

Backup & restore

CSV import merges attendance statuses into this app; it does not replace existing records. Dates and employee names are matched from the spreadsheet. Missing IN/OUT times remain blank. Export a JSON backup before importing.

Keep backup files somewhere safe, such as your Mac. Restoring a JSON backup replaces the current data in this app. Export a backup first and only restore a file you trust.

Data protection

Records are stored in this browser on this device. They do not automatically sync to your other iPhone, iPad, or Mac. Export JSON backups regularly. Clearing Safari website data or removing the browser's stored data may erase records.
